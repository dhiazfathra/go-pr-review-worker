# ADR-0000: Template

## Status

Accepted (2026-09-01)

## Context

Every non-trivial decision in this repository is recorded as an ADR so a reader
of the tree can reconstruct _why_ it looks the way it does. ADRs are numbered
sequentially, never deleted; a superseded one is marked
`Superseded by ADR-NNNN` and left in place.

## Decision

Each ADR uses the sections below.

- **Title** — `ADR-NNNN: <imperative summary>`
- **Status** — Accepted | Proposed | Superseded by ADR-NNNN, with a date
- **Context** — the forces in play, including what is already true
- **Decision** — what was chosen, in active voice
- **Alternatives considered** — each with pros, cons, and why it lost
- **Consequences** — what becomes easier, what becomes harder

## Consequences

A reviewer can diff a decision against its rationale. Writing an ADR costs a few
minutes per decision and saves the same argument being had twice.
